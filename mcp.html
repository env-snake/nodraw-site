MCP: connect an AI agent

NoDraw contains a local MCP server. An MCP-capable desktop agent can inspect the active VMF, find assets, edit geometry and entities, take viewport snapshots and control compilation. NoDraw provides the editor tools; your AI client supplies the model.

1. Enable the server in NoDraw

  1. Start NoDraw and open a VMF, or create a new map with Ctrl+N. Use a map copy for your first editing test.
  2. Press Ctrl+, to open Settings. Select Integrations and locate MCP server (AI agents).
  3. Enable Let AI agents edit the open map (localhost only). Wait for Running on http://127.0.0.1:47823/mcp. Use the URL actually displayed in your editor.
  4. Leave NoDraw running while the agent works. The copy button next to the command copies the Claude Code setup command.

Endpoint: http://127.0.0.1:47823/mcp · Transport: HTTP · Default port: 47823 · NoDraw does not require an API key for this local connection.

2. Connect your MCP client

Codex

With the Codex CLI installed, run this command in a terminal:

codex mcp add nodraw --url http://127.0.0.1:47823/mcp

Alternatively, add this table to your Codex config.toml. Keep any existing configuration; add one nodraw entry only. Reload the client connection after changing its configuration.

[mcp_servers.nodraw]
url = "http://127.0.0.1:47823/mcp"
tool_timeout_sec = 300

Claude Code

claude mcp add --transport http nodraw http://127.0.0.1:47823/mcp

Open /mcp in Claude Code and check that nodraw is Connected. You can also inspect it from a terminal with claude mcp get nodraw.

Other desktop clients

Add a server named nodraw using HTTP / Streamable HTTP and the same URL. Use the client’s own configuration format. Choose URL transport rather than a command that starts NoDraw as a stdio server.

The client must reach localhost on the PC running NoDraw. A remote cloud session cannot connect to this Windows localhost endpoint directly.

3. Verify without editing the map

Ask the agent: “Call guide, then map_info and selection. Tell me which map is open and what is selected. Do not modify or save anything.” A working connection returns the current map and its counts; it does not create geometry.

Optional Windows transport check (PowerShell): this requests the tool list, not an edit.

Invoke-RestMethod -Uri "http://127.0.0.1:47823/mcp" `
  -Method Post -ContentType "application/json" `
  -Body '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

A browser GET request can show HTTP 405 because the endpoint expects POST. That alone does not mean the server is broken.

4. A first editing task

On an empty test map, ask: “Create a 256 × 256 × 128 unit block at the origin using DEV/DEV_MEASUREGENERIC01B. Show it with the camera, take a snapshot and stop. Do not save or compile.”

The corresponding create_block arguments are:

{"min":[0,0,0],"max":[256,256,128],
 "material":"DEV/DEV_MEASUREGENERIC01B"}

Editing commands normally create undo steps. Inspect the result and use Ctrl+Z in NoDraw to undo the block. Read-only calls and camera movement are not geometry edits. Use batch with group when the agent should combine supported edits into one step.

5. What an agent can do

ToolsPurpose
guide, map_info, selection, list_objectsInspect the map, selected objects, classes and bounds.
find_assets, reference_info, copy_from_referenceFind real content paths and copy parts of a reference VMF.
create_block, create_primitive, mesh, boolean, textureBuild and edit brushes, geometry and UVs.
create_terrain, sculpt, paint_blend, sew, pathShape terrain, paint blends, sew borders and build paths.
create_entity, set_keys, transform, connections, visgroupPlace props/entities, change keys and manage I/O and visibility.
camera, snapshot, view, history, undoInspect the visible result and review or undo edits.
compile, cubemaps, saveCompile, build cubemaps or save when requested.

Tool availability and arguments depend on the installed build. Have the client read the live tool schemas rather than inventing parameters.

6. Common connection problems

Connection refused

Check that NoDraw is running and the MCP checkbox is enabled. Copy the URL from Integrations, including /mcp.

Port is busy

Another NoDraw instance or another program may be using 47823. Check the message in Integrations and connect to the intended editor.

HTTP 503 with a proxy

Exclude 127.0.0.1 and localhost from the proxy for the process running your AI client. In PowerShell: $env:NO_PROXY="127.0.0.1,localhost"; launch the client from that terminal.

Connected, but no map is open

Open or create a VMF. map_info and editing tools require an active map; transport discovery can work without one.

Missing models or materials

Set the game folder and content mounts in NoDraw. The agent should use find_assets instead of guessing paths.

Timeout during a long action

Allow a longer tool timeout in the client when appropriate. Check the editor and compile status before repeating a command, so an edit is not performed twice.

Disconnect by disabling Let AI agents edit the open map in NoDraw. This stops the server; it does not undo edits already made.
