Project workflow

Development guide — public downloads are currently paused. See Changelog for release status.

Organise the map with User and Auto VisGroups, inspect entities in Properties, and use the Pack tools for map dependencies. Welcome provides recent maps and autosave recovery. The local MCP interface supports inspection and editing from connected tools.

Workflow

  1. Welcome offers New map, Open VMF, recent maps and autosave recovery. Its banner uses the NoDraw editor grid and logo.
  2. Scene lists User and Auto VisGroups with one outer scroll area. Show all and Hide all control visibility; user-group changes can be undone.
  3. Selecting a brush entity opens Properties; selecting world brushes opens Tool. Narrow panels keep colour, model, reset and distance buttons inside the available width.
  4. Installed beta versions support startup update checks and Help → Check for updates. A future update requires a newly published installer and manifest. The latest central Yes / No prompt is a development change, not part of the withdrawn public packages.
