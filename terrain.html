Displacements and roads

Development guide — public downloads are currently paused. See Changelog for release status.

Sculpt terrain and paint material blends without leaving the editor. Auto-sew maintains shared edges; its toggle is available in Select → Displacements. Path Tool builds road ribbons with width, elevation and blend controls, or reshapes existing displacement surfaces.

Workflow

  1. Select displacements in Select → Displacements; enable Auto-sew there when shared borders should follow edits.
  2. Use sculpt brushes to adjust height and paint material blends. Alt+W toggles the displacement wireframe.
  3. Path Tool builds road ribbons or reshapes terrain. Adjust width, elevation and blends, then inspect joins before applying.
