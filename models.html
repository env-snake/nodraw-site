Propper and model sources

Development guide — public downloads are currently paused. See Changelog for release status.

Convert map geometry into a compiled model, preserving material blends and UVs. Keep source LODs or generate simplified levels with adjustable thresholds. Model Viewer provides skin and LOD previews, QC/SMD decompilation and recompilation, with a route to Blender for mesh editing.

Workflow

  1. Choose a model in Assets → Models and open Model Viewer. Preview skins, LODs, wireframe and collision. The lower corner shows geometry statistics and the view axes.
  2. Sources shares the window with the preview: source controls on the left and QC/build log below. Decompile creates QC/SMD; compile uses the configured StudioMDL.
  3. Open in Blender imports the model, materials and visible collision by default. Visual and physics meshes are separated. Blender and Blender Source Tools must be installed. Export the SMD filenames referenced by the QC before rebuilding.
  4. Propper converts selected map geometry into a model. Choose source LODs, generated LODs with thresholds and triangle ratios, or LOD0 only. Source geometry is retained for later edits.

This is the static-model source workflow. Full modelling, rigging and animation editing are deferred. Blender preview nodes do not replace the original in-game VMT shaders.
